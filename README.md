# Customer Churn Analysis & Retention Insights

## Overview

This project analyzes the **Telco Customer Churn dataset** using Power BI to identify customer churn patterns, retentions, subscription behavior, and high-risk customer segments. The dashboard provides interactive insights to help businesses reduce customer attrition and improve customer retention strategies.

## Tools Used

* Microsoft Power BI Desktop
* Power Query
* DAX

## Dashboard Features

* KPI Cards (Total Customers, Churn Rate, Active Customers, Average Tenure, Average Active Tenure)
* Churn Analysis by Contract Type
* Churn Analysis by Internet Service
* Churn Analysis by Payment Method
* Churn Analysis by Gender
* Customer Lifetime Pattern Analysis
* High-Risk Customer Segment Matrix
* Monthly Charges vs Churn Analysis
* Interactive Slicers (Gender, Contract, Internet Service, Payment Method, Churn)
* Business Insights & Retention Recommendations

## Key Objectives

* Analyze customer churn and retention trends
* Identify customer segments with the highest churn risk
* Understand customer lifetime patterns
* Evaluate the impact of contract types on retention
* Analyze the relationship between payment methods and churn
* Identify key factors influencing customer retention
* Provide data-driven recommendations to reduce churn

## Outcome

The dashboard transforms raw customer subscription data into actionable business insights, enabling organizations to identify churn risks, improve customer retention strategies, increase customer lifetime value, and support sustainable business growth.
